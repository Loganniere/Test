# Dungeon Crawler Projects

This repository contains two small dungeon crawler examples.

- `DungeonCrawler` is a console-based game written in C#.
- `DungeonCrawler2D` is a simple 2D browser game built with HTML5 canvas and JavaScript.

## Running the 2D version
Open `DungeonCrawler2D/index.html` in a web browser and use the arrow keys to move your character.
Collect items to power up and defeat all monsters.
